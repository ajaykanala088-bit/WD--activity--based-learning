# 🛒 E-Commerce Website

## 📌 Project Description
This project is a simple, responsive e-commerce website developed using HTML and CSS. It displays products with prices, discounts, ratings, descriptions, and shopping buttons.

## 🎯 Features
- Responsive product grid layout
- Navigation bar with Home, Products, Categories, and Contact
- Product images and descriptions
- Product prices and discount labels
- Customer ratings
- Add to Cart buttons
- Promotional banners
- Simple and attractive user interface

## 🛠️ Technologies Used
- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Optional interactive features

## 📂 Project Structure
```text
e-commerce-website/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run the Project
1. Download or copy the project files.
2. Save them in one folder.
3. Open `index.html` in your web browser.
4. Explore the products and website interface.

## 💻 Requirements
- A web browser such as Google Chrome.
- A text editor such as Visual Studio Code.
- No additional software installation is required.
